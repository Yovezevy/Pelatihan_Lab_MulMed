# Pelatihan_Lab_MulMed

## Fungsi
Repositori materi praktikum dan template awal web portofolio statis untuk kegiatan pelatihan dasar pengembangan web di laboratorium multimedia.

## Bahasa dan Stack
HTML5, CSS3, Tailwind CSS

## Cara Build dan Menjalankan
Buka berkas index.html langsung menggunakan peramban web atau gunakan ekstensi server lokal.

## Fitur Utama
- Template starter portofolio web statis.
- Dokumentasi modul jawaban dan latihan praktikum multimedia.
- Penataan gaya visual menggunakan kombinasi CSS murni dan Tailwind CSS via CDN.

## Status
Stabil
